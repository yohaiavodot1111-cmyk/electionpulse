▧ בסיס השוואה — בחירות קודמות

נתונים סופיים
מקור: ועדת הבחירות המרכזית והכנסת. בחלק ממערכות הבחירות נתוני ההשתתפות במהלך יום הבחירות מבוססים על מדגם ולא על ספירה מלאה.
חדשות: בודק מקורות ציבוריים. לפרסומי X ניתן לפתוח חיפוש חי ב־X ↗ (ללא API מחובר).
נתונים היסטוריים: ועדת הבחירות המרכזית. הבחירות לכנסת ה־26: מספר בעלי זכות בחירה 7,331,981; 12,018 קלפיות. נתונים שדווחו פומבית מוצגים עם שעת המדידה; אין חיבור ישיר מאומת לשרת ועדת הבחירות.

⚙ הגדרת מקור נתונים והתעדכנות

העדכונים נמשכים אוטומטית מפרסומים פומביים של שיעורי ההשתתפות. כשהמקור אינו זמין יוצג הנתון האחרון שנבדק עם שעת המדידה. אין צורך להגדיר ELECTION_FEED_URL.

עדכון ידני מסומן

כאשר יש בידיך עדכון מאומת שטרם זמין בפיד, אפשר להזין אותו ידנית. במצב זה המקור יסומן "ידני — לא אומת אוטומטית".

העדפות הרענון, הדיווחים הידניים וקובצי הייבוא נשמרים בדפדפן שלך בלבד ואינם מסתנכרנים בין משתמשים. החיבור הציבורי מוגדר אוטומטית. מקור החדשות אינו API רשמי של הוועדה.
