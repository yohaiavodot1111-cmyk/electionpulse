# ElectionPulse | דשבורד בחירות ישראל — גרסה לפריסה ב־Vercel

פרויקט אינטרנטי בעברית, RTL, בעיצוב בהיר. אין צורך ב־API Key, בשרת Python או בבסיס נתונים לצורך **סקירת ההיסטוריה, חישוב מודד המנדט ומפת ההצבעה הממשלתית**.

## לפרסם את האתר — 4 שלבים

1. פתח את ZIP וחלץ את הקבצים. **אין להעלות את ה־ZIP עצמו לתוך המאגר**: יש להעלות את הקבצים והתיקיות שבתוכו.
2. היכנס ל־[github.com/new](https://github.com/new), צור Repository בשם `electionpulse` ולחץ **Add file → Upload files**. גרור את **כל התוכן** (כולל `index.html`, תיקיות `api`, `lib`, `tests` וקובץ `vercel.json`) ולחץ **Commit changes**.
3. היכנס ל־[vercel.com/new](https://vercel.com/new), בחר **Import Git Repository → electionpulse**. Framework Preset: **Other**; Root Directory: **./**; אין צורך להגדיר משתני סביבה. לחץ **Deploy**.
4. Vercel מציג כתובת קבועה בפורמט `https://electionpulse-xxxx.vercel.app`. פתח אותה — זו המערכת.

## עדכון עתידי

ב־GitHub → בחר את הקובץ לשינוי → כפתור העיפרון **Edit** → **Commit changes**. Vercel מבצעת פריסה אוטומטית לאחר העדכון בענף המקושר. כדי לעדכן את כל הקבצים בבת אחת, אפשר להעלות אותם מחדש למאגר ולבצע Commit.

## מה עובד ללא כל הגדרה

- דשבורד עם גרפים, מסננים, מצב הדגמה **מסומן כדמו**, ייצוא CSV, וייבוא JSON/CSV.
- **השוואות ארציות תוך-יומיות** לכנסת ה־25/24/23, מתוך טבלאות היסטוריות מוטמעות. מדדי ההצבעה התוך-יומיים מבוססי מדגם; אינטרפולציה מסומנת.
- **השוואות סופיות דינמיות לפי יישוב** בין הכנסת ה־21–25, ממסמכי JSON פתוחים של `israelvoting.com/data` (ארכיון עצמאי המבוסס על מקורות ממשלתיים).
- **חישוב מודד קולות למנדט היסטורי** מרשימות שקיבלו מושבים וחלקן בקולות; מוצג בנפרד מחלוקת בדר–עופר הסופית.
- **מפת הבחירות הממשלתית** `elections.govmap.gov.il` בתוך הדשבורד, עם כפתור לפתיחה בטאב חדש אם האתר חוסם iframe.
- **כותרות חדשות ציבוריות**, באמצעות RSS ציבורי של Google News ככל שהמקור זמין. קישורים ונימוקי מקור מוצגים; התוכן אינו מאומת אוטומטית.
- ציר תיעוד פרסומים שאפשר להוסיף באופן ידני וקישור לחיפוש ציבורי ברשת X.
- ממשק API בענן: `/api/history?round=25`, `/api/media`, `/api/state`.
- בדיקת דיווחי השתתפות ורענון אוטומטי של הדשבורד כל 60 שניות (ניתן לשנות בהגדרות הדשבורד) ושל חדשות כל חמש דקות **כל עוד הדף פתוח**.

## מה אינו מופיע כנתון אמת עד שיש מקור נתונים מאומת

- **הכרטיס הארצי מציג דיווחי השתתפות מתוארכים שפורסמו בתקשורת, ללא צורך בהגדרת משתנה סביבה.** הנתונים מתחילים מדיווחים לשעות 10:00, 12:00, 14:00 ביום הבחירות 27.10.2026, ונעשה ניסיון לזהות עדכונים נוספים במקור חדשות ציבורי. שעת המדידה מוצגת בנפרד משעת בדיקת האתר. הפיד אינו API רשמי ישיר של ועדת הבחירות, ולכן עדכון חדש אינו מובטח בכל רענון.
- בלוח הספירה לא יופיעו מספרי מנדטים חיים לפני פרסום הנתונים הרשמיים. כל קובץ הנושא חותמת **סביבת בדיקות** אסור להציגו כתוצאה רשמית.
- **אין חיבור מורשה ישיר ל־X** (מחייב API/הרשאות מתאימים). יש קישור לחיפוש פומבי, ולא פיד המציג עצמו כציוצים שנמשכו אוטומטית.
- הוספת ידיעות באופן ידני וייבוא קובצי CSV נשמרים **בדפדפן בלבד**, ולא מסונכרנים בין מכשירים.
- אין כאן מערכת הרשמה/משתמשים, ולכן האתר ציבורי למי שמכיר את הכתובת.

### מאין נמשכים שיעורי ההצבעה

`api/state.js` מחזיר דיווחי חדשות עם שעות מדידה ומנסה לעדכן אותם מתוך מקור פומבי. אם המקור אינו נגיש, האתר מציג את הדיווח האחרון ששמור בקוד — לא מספר פיקטיבי. לקריאה ידנית של נתוני המקור: https://www.israelhayom.co.il/news/politics/article/21716830 (10:00), https://www.jdn.co.il/news/2755711/ (12:00), https://www.okn.co.il/news/73351/ (14:00). אין API רשמי מאומת בשלב הזה. אפשר להחליף את המקור בפונקציית השרת לאחר אימות פיד ועדת הבחירות. אין להגדיר את קובצי הכנסת ה־25 כמקור לתוצאות הכנסת ה־26 ואין להתייחס לנתוני הדמה של סביבת הבדיקות כנתוני אמת. פונקציית המקור אינה כוללת זיהוי אוטומטי של כל פורמט חדש; במידת הצורך נדרש להוסיף מתאם.

## פיתוח ובדיקות (רשות)

הפרויקט משתמש ב־Node 20 ומעלה. לא דרוש `npm install` כי אין תלויות חיצוניות.

```bash
npm run dev
# http://localhost:8787
npm test
```

**הערה:** שרת מקומי נועד לבדיקה בלבד. ב־Vercel פונקציות `api/*.js` פועלות בשרתless ואין צורך להשאיר מחשב פתוח.
